# OmgManager — Feature Screenshots

The screenshots below are taken from the **V9.3.12 interface** and used to illustrate features in the **V9.3.13** release. They are not claimed to be new V9.3.13 captures.

The original collection, with the author's Chinese descriptions, is available in the [Google Drive screenshot archive](https://drive.google.com/file/d/1MAxqb5qpS63dOKp-a4rLRIrddwVUqL5T/view). GitHub-hosted full-size images will be added to this gallery when the image assets are uploaded.

## What to look for

| Screen | Function demonstrated |
| --- | --- |
| 02 — Music library | Track list and the central music collection view. |
| 03 — Albums | Album-based music browsing. |
| 04 — Artists | Artist-based music browsing. |
| 05 — Playlists | Device playlist list and management. |
| 08 / 09 — Playlist editor | Edit playlists directly on the player, without an intermediate SonicStage PC-library sync. |
| 07 — Import from M3U | Select local M3U entries for device import; use existing library tracks to create playlists. |
| 06 — Music import | Device music import workflow. |
| 12 — Export music | Export supported music and playlist information to the PC, including migration workflows. |
| 10 / 11 — Converter | Standalone conversion, MP3 by default and ATRAC only with a separately installed compatible encoder. |
| 13 — Library maintenance | OMGAUDIO repair or maintenance features, subject to device limitations and backup requirements. |
| 01 — Launch screen | Application identity. |

## Additional capabilities documented by the author

The author's notes also describe **PL-format playlist backup and restore**, and the ability to **initialize an OMGAUDIO directory anywhere on a PC without physically connecting a Walkman**. The latter is useful for inspecting or preparing a library, but an arbitrary directory does not prove compatibility with every physical device.

**Always back up the complete OMGAUDIO folder before changing or repairing a real player's library.**

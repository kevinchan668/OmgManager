# OMGAUDIO 数据库研究：整合摘要

本页为英文研究概述的中文导读。完整整合研究内容见 [English research overview](README.md)。

研究主题包括：20 字节 ContentKey 与跨表曲目身份、TREE/GPLB/TPLB 分类树的物理顺序、TREE22 播放列表成员共用存储、TREE01 传输批次结构、数据库事务式写回，以及 NW-A608 普通删除、修改时间变化与 Simple Mode 的实验观察。

**重要边界：** 研究区分已观察的数据、工作性机制解释和尚未证实的假设。早期 S638 流程中的时间戳处理经验不应被当作对所有设备和操作都成立的规则。A608 数据显示，DAT 文件内容是否变化与其修改时间是否变化并不存在简单的一对一关系。

目前英文主页提供去重后的核心结论。字段级十六进制记录、完整样本来源和实验复现步骤可在后续研究文档中进一步补充。当前公开研究资料不包含应用源代码。
